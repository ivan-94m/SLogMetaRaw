S-Log MetaRaw

Sony metadata and development controls for DaVinci Resolve 21 · guide · v@VERSION@

1What it is, and what it is not

Sony cameras write the shooting setup into every file: Kelvin, tint, EI, lens, aperture, shutter, colour profile. Resolve uses that data only for FX6 and FX9 MXF files; for MP4 (FX30, FX3, a7 and a6000 series) it ignores it. S-Log MetaRaw reads it and uses it: exposure and white balance start from the as-shot values and work in linear light, with the curves and gamuts Sony publishes.

It is not raw. Colour science applied rigorously makes the image behave in a way that reminds you of a raw file: white balance shifts cleanly, exposure moves like a stop of light. But a log MP4 is already compressed, 8 or 10 bit, with the camera's noise reduction applied. On heavy work colour science alone is not enough: as soon as you push past the camera's limits, the missing information in the image shows (banding, noise in lifted shadows, clipped highlights that stay clipped). Exposing well at the camera is still what matters most.

3Install

  1. Double-click Installa S-Log MetaRaw.pkg. It is not signed with an Apple certificate: the first time, right-click › Open. It asks for the Mac password (the plugin goes in a system folder).
  2. The installer deletes Resolve's plugin cache, so the new panel and the Detail node show up.
  3. Restart DaVinci Resolve. Every install starts clean. To remove every version: Disinstalla S-Log MetaRaw.command (right-click › Open; your CSV exports stay unless you ask).

4Workflow

  1. Import the footage and open the script: 1 · Read metadata, then 2 · Write to Resolve.
  2. On the Color page put S-Log MetaRaw first: it takes the clip's EI, Kelvin and tint, and at those values it changes nothing. Copied onto another clip, it resets itself with that clip's data.
  3. Correct white balance and exposure in the node, with the false colour views. Then the Toni (tones).
  4. For local recovery, Texture, Clarity or Dehaze, add S-Log MetaRaw Detail right after.
  5. Then the rest of the grade and, last, the output CST, LUT or DRT. Until there, stay in log or DWG (page 3).

5Good to know

  • Original files are never modified: no transcoding, no rewrapping.
  • With non-log profiles (Cine, HLG, S-Cinetone) the nodes stay neutral and say so. For ProRes from external recorders there is Avanzate › Sblocca controlli senza metadata (unlock without metadata).
  • False colour views replace the image: turn them off before you render.
  • The version sits at the top of the nodes: once a day it asks GitHub whether there is a newer one (the request carries only the version number) and turns 🟢 if so; a click opens the download in the browser. To turn it off, create the file ~/Library/Application Support/SLogMetaRaw/no_update_check.

The script

Workspace › Scripts › S-Log MetaRaw

One row of buttons, one row of options, the clip list and, below it, everything read from the selected clip, grouped as in Catalyst Browse. The script reads the files; it never modifies them. Its window follows Resolve's language; the nodes' panels are in Italian, so their labels appear here with a translation.

ClipsWhole Media Pool, or Selected clips in the Media Pool.
1 · Read metadataOne row per clip: camera, lens, aperture, shutter, EI, WB, colour space, data level. The Status column says read, what changed during the take (changed: aperture, focus) or why a clip was skipped. Click a row to see everything.
2 · Write to ResolveFills the Media Pool fields: Metadata, columns, keywords, Camera Notes, data burn-in. Fixes values Resolve reads wrong from MXF (e.g. Camera Aperture F53343 on the FX6).
Export CSVThe values Resolve has no field for (EI, tint, WB mode, focus distance, capture gamma…). In Resolve: File › Import › Metadata, with create custom fields on.
Camera tagoff · adds camera, gamma and primaries to the keywords.
Overwrite metadataon · replaces values Resolve already wrote; off, it fills only the empty fields.
Correct the Data Levelon · sets each clip's Data Level to Full (log) or Video (709, Cine, HLG). This is the real fix: it holds for the whole project, scopes and exports included.
Also set Input Color Spaceoff · for colour-managed projects. Careful: a script cannot set it back to Project, only you can, by hand.
VersionBottom right: click it to check GitHub; it turns green when there is a newer release.
It reads at most 24 samples of the metadata track per clip, within one second: nothing is decoded, and a multi-GB file costs about 100 KB of reading. A disk that does not answer is skipped once, with a message (10 s for the first clip of a volume, 6 s for the others). Running it right after import means the nodes find the data ready.

The S-Log MetaRaw node

Color › OpenFX · first node, before CST and LUT

It shows the camera at the top and sets Color Temp, Tint and Exposure to the as-shot values: there it changes nothing. It is a starting point, not a look. Settings are saved per clip; Rileggi metadata (re-read) resets everything to the camera values and writes that clip's metadata into the Media Pool.

Decode UsingClip lets you change the controls; Camera metadata locks them to the as-shot values.
White BalanceAs shot or presets (Daylight, Cloudy, Shade, Tungsten, Fluorescent, Flash); moving a slider switches it to Custom.
Color Temp · TintBradford chromatic adaptation in linear light, from the white the camera recorded. Higher Temp warms; positive Tint goes towards magenta.
ExposureIn EI: double the EI is exactly +1 stop, in linear light, before any curve.
Color Space · GammaOutput, like a Color Space Transform. Timeline does not convert: leave them there in a colour-managed project. To grade in DWG: DaVinci WG · DaVinci Intermediate. Rec.709 is a CST without tone mapping (highlights past Bianco clip) and shuts out the Detail node: better an output CST at the end.

False colour: one view per control, above its slider

ExposureBands in stops around 18% grey, ARRI style: middle grey · one stop over (skin) · near clip · clip · deep shadow · black. The rest in grey.
TemperatureAs in CineMatch: the picture turns grey, blue = cool cast, raise Color Temp; orange = warm, lower it. Near-neutral casts are boosted up to 8×.
Tintgreen = raise Tint; magenta = lower it. Each view reacts only to its own slider.
Pick a surface that should be neutral and move the slider until it stays grey; alternate Temp and Tint a couple of times. For exposure: middle grey in green, skin in pink. The view replaces the image: turn it off before you render.

The S-Log MetaRaw node

Toni (tones), Zone, Avanzate (advanced)

Tones: Highlights is a film shoulder; the others are exposures for a zone, in stops from 18% grey, where the image moves as with an exposure and texture is kept. No combination can solarise.

ContrastTurns around the Pivot; at +100 the slope doubles, at −100 it halves, with bounded ends.
HighlightsNegative: compresses the highlights with a slope that falls towards the top, like film; at −100 the recorded maximum lands on Bianco, with no grey veil and no clip. Grey and below stay put. Positive: more snap.
Bianco (stop)Where that maximum lands, and Soft Clip's roof. 2.5 = Rec.709 white through a CST without tone mapping; with a DRT (ACES, AgX, DaVinci) raise it to 4-5.
Shadows · WhitesShadows: the tones below −1 stop, 100 = 2 stops; lifts black too, hold it with Blacks. Whites: from +3.5 stops to clip, 100 = 1 stop.
BlacksA linear veil: moves black (−3 / +1 stop) without moving grey.
Vibrance · SaturationAround luminance, the same in every colour space. Vibrance protects skin tones.
Zone (closed)Black, Shadow, Light, Specular: Exp (stops), Sat, Range (edge), Falloff (transition). Soft Clip folds the highlights under a roof: containment, not recovery. Zone false colour shows which zone moves each pixel.
AvanzateIngresso nodo (node input; Automatico asks Resolve) · Data level in ingresso (fixes the code-value scale when Resolve gets it wrong) · Stato (status) · Sblocca controlli senza metadata (unlock without metadata): for ProRes or unreadable clips, type the shooting EI, Kelvin and tint and the controls come alive.
Recipes · burning highlights: Highlights −50…−100 (with a DRT after, Bianco at 4-5) · backlight: Shadows +30…+60 and Blacks −20…−40 · film look: Contrast +20…+30, Highlights −60 · noisy shadows: Shadow Sat −30…−50.
The limit, plainly: a pointwise node that compresses a band also compresses its texture. Recovery that keeps it lives in the Detail node. Generate LUT exports this node: 65 points is best.

The S-Log MetaRaw Detail node

Color › OpenFX · after S-Log MetaRaw, before the output CST

The creative node. It works by areas, over an edge-aware base: it moves large areas of light without flattening the fine detail. That is the "Lightroom" part of Highlights and Shadows a pointwise node cannot do.

In and Out are the same space: it decodes what it receives to linear light and writes it back in the same encoding. It only takes scene log encodings: S-Log3, S-Log2, DaVinci WG/Intermediate, ACEScct. Not Rec.709, Gamma 2.4 or sRGB: those are already for the monitor, with highlights clipped at white.

RecommendedMain node on DaVinci WG · DaVinci Intermediate → Detail with Ingresso nodo (node input) on DaVinci WG/Intermediate (on an unmanaged timeline you must declare it) → grade in DWG → last, an output CST DaVinci WG/Intermediate → Rec.709 · Gamma 2.4, DaVinci tone mapping. With tone mapping after, set Bianco to 4-5 in both nodes.
All in logMain node on Timeline → Detail on Automatic (uses the clip's S-Log3) → CST S-Gamut3.Cine/S-Log3 → Rec.709 or DWG.
Colour managedTimeline in DaVinci WG/Intermediate: both on Timeline and Automatic, the project does the output.
AvoidMain node in Rec.709 → Detail: Automatic cannot know, decodes it as S-Log3 (or as the timeline), and the highlights are already clipped.
Gamma dinamicadynamic range · Local Highlights compresses the large bright areas and keeps, even strengthens, the texture: the sky gets deeper and the clouds stay defined (the main node's softens it, like film). Local Shadows opens (+) or closes (−) shadows; Local Contrast the contrast of large areas. Gain and base views.
Presenzapresence · Texture: fine detail; does not raise grain below the noise threshold; negative smooths. Clarity: local contrast on the midtones. Dehaze: removes (+) or adds (−) haze.
Zone localilocal zones · the main node's zones, applied to areas instead of pixels.
Avanzate · Veloadvanced · haze · detail preservation, radius, Soglia bordi (edge threshold), noise threshold, Clarity centre, Bianco for Local Highlights, input. You set the haze (level and colour): never guessed per frame.
To start · Local Highlights −30…−60 and Local Shadows +20…+50 · Texture +10…+30 · Clarity in moderation · Dehaze only on real haze, with the haze level set to the scene.
Measured limits · Local Highlights −100: halo under 3% on the dark side of edges. Local Shadows and zones at ±100: on a hard one-stop edge the halo reaches about 12% of the step (4-6% on 2-3 stops): if you see it, lower Soglia bordi (edge threshold). Next to strong edges grain can grow 1.25-1.7×. It is spatial: Generate LUT leaves it out together with the rest of its node, so keep it in a node of its own. Same look at full resolution, in proxy and in the viewer; on Metal a UHD frame costs about 6-18 ms.
