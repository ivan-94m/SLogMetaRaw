S-Log MetaRaw

Sony metadata and Camera Raw controls for DaVinci Resolve · quick guide · v1.0

1What it is for

With colour science and the recorded metadata you can work on the essential parameters of Sony mirrorless cameras — white balance, exposure, colour space and curve — as if they were raw files. Where possible, and only with a log profile (S-Log2 / S-Log3). The cameras store that data in every file, but Resolve only reads it from FX6 and FX9 MXF.

2The two tools

S-Log MetaRaw script  the whole project in one go

Reads the shooting data from Sony MP4 and MXF files (FX30, FX3, Alpha, a6300, FX6…) and writes it into the Media Pool for the selected clips or the entire project: Metadata panel, columns, keywords for smart bins, data burn-in, CSV export. It also shows everything it read, like Catalyst Browse.
Workspace › Scripts › S-Log MetaRaw

S-Log MetaRaw plugin  clip by clip, in Color

A node with the controls of the Camera Raw "Sony Video" panel, which Resolve does not enable for MP4. It sets itself to that clip's values and interprets the clip as it was recorded: white balance and exposure start from the right numbers.

3Install and contents

  1. Double-click Installa S-Log MetaRaw.pkg. It is not signed with an Apple certificate: if macOS blocks it, right-click › Open.
  2. Your Mac password is required, because the plugin goes into a system folder.
  3. Restart DaVinci Resolve. To remove everything: Disinstalla S-Log MetaRaw.command.

4How to use it

  1. Import your footage into the Media Pool.
  2. Workspace › Scripts › S-Log MetaRaw: pick the source (selected clips, a bin or the whole Media Pool), then 1 · Leggi metadata (read) and 2 · Scrivi in Resolve (write).
  3. Color page: add S-Log MetaRaw as the first node, before CST and LUTs. It sets Color Temp, Tint and Exposure to the as-shot values, where the image is unchanged. Copy it to another clip and it reloads that clip's data.

5The plugin controls

Decode UsingClip uses the controls; Camera metadata returns to the as-shot values and greys them out.
White BalanceAs shot = camera values; presets Daylight, Cloudy, Shade, Tungsten, Fluorescent, Flash; moving the sliders switches to Custom.
Color Temp · TintWhite balance in linear light with chromatic adaptation, starting from the as-shot white.
ExposureIn EI: double the EI = +1 stop.
Color Space · GammaLike a Color Space Transform: Timeline does not convert; the other choices do (Rec.709, Gamma 2.4, SLog3, ACES…).
Toni (tones)Highlights says, in stops, where the top of the recorded container lands: negative presses it down (at −100 onto the Rec.709 peak), positive stretches the top of the scale. It never clips and leaves the midtones alone. Shadows opens the shadows without lifting black. Color Recovery sets how much colour the press gives back: right keeps the scene colour, left goes towards film. Plus Color Boost, Saturation, Contrast.
False colorThree measuring views, one per control: exposure, temperature and tint. They replace the image: switch them off before you render.
Rileggi metadataRe-reads the clip and returns everything to the camera values.
AvanzateDetected input space, Data level (corrects the code-value scale when Resolve gets it wrong) and status. Dati di ripresa: lens, focal length, iris, focus, shutter, ISO/EI, white balance, data level, fps, ND, camera LUT.

6Good to know

  • Your original files are never modified: no transcoding, no rewrapping.
  • FX6 and FX9 MXF already have the native Camera Raw panel: S-Log MetaRaw is for MP4 (XAVC S, S-I, HS).
  • An S-Log2 or S-Log3 profile is required; with other profiles the node stays neutral. If the camera does not record Kelvin (the a6300, for example) the value is estimated from the preset and flagged in the panel.
  • Tested only on DaVinci Resolve Studio 21 (macOS), by Ivan: earlier versions were not tried (the plugin uses features introduced with Resolve 21).
